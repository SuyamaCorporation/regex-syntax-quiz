# 29 - 正規表現構文4択クイズ

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: regex-syntax-quiz

## 概要
正規表現の構文・マッチ結果・グループ化を問う25問4択クイズ。クイズ下部にライブ正規表現テスターを常時表示し、学習内容をその場で確認できる。

## 機能
- 25問の問題バンク（量指定子・文字クラス・アサーション・グループ・実用パターンを網羅）
- パターンと対象文字列を視覚的に表示してから4択回答
- 回答後に解説を表示
- ハイスコアをlocalStorageに保存
- ライブ正規表現テスター（パターン・フラグ・文字列を入力、マッチをハイライト表示）
- キャプチャグループの結果も表示
